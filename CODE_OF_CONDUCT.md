# Code of Conduct

AgentLogistics uses a simple contributor standard: be direct, practical, and
respectful.

Project discussion should focus on the work: logistics reasoning quality,
evidence, safety boundaries, validation, documentation, and implementation
tradeoffs. Harassment, personal attacks, discriminatory conduct, or repeated
bad-faith disruption are not acceptable.

Maintainers may remove comments, issues, pull requests, or contributors that
undermine productive project work.
