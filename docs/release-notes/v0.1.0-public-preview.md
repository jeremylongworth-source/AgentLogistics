# v0.1.0 Public Preview Release Notes

This public preview makes AgentLogistics available as a GitHub CLI agent-skills
source for logistics, warehousing, inventory, freight, safety-boundary, and
operations-analysis workflows.

Recommended GitHub release state: public preview

Reason: AgentLogistics has completed roadmap waves AL-00 through AL-25, passes
local repository validation, passes GitHub Actions validation, passes source
link auditing, and passes `gh skill publish --dry-run`. The repository is still
pre-v1 because the AL-25 audit requires live model scoring, source freshness
review over time, expanded numerical fixtures, release-setting decisions, and a
v1-specific release gate before a stable v1 tag.

## What Is Included

- 143 validated core skill packages.
- 42 validated specialization packages.
- 14 validated professional skillsets.
- 169 taxonomy skill candidates with duplicate-slug validation.
- Shared formula, glossary, schema, and output-template foundations.
- Canada, United States, food cold-chain, dangerous-goods, and international
  logistics specialization source maps.
- Repository-wide integration scenarios and fixtures.
- GitHub Actions validation and source-link audit workflows.
- GitHub Copilot and `gh skill` setup documentation.

## Install Examples

Preview a skill:

```powershell
gh skill preview jeremylongworth-source/AgentLogistics inventory-control/calculate-reorder-point
```

Install a skill for GitHub Copilot at project scope:

```powershell
gh skill install jeremylongworth-source/AgentLogistics inventory-control/calculate-reorder-point --agent github-copilot --scope project --pin v0.1.0-public-preview
```

## Maturity Boundary

This is not a v1 release. AgentLogistics provides decision-support content and
must not be treated as legal, regulatory, engineering, equipment, customs,
food-safety, dangerous-goods, operator-certification, or professional approval.

Users must verify current requirements with the applicable authority before
acting on jurisdiction-specific, safety-sensitive, or regulated material.
